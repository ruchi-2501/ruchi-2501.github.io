HOW TO PREVIEW
1. Extract this ZIP file.
2. Open the ruchi_portfolio folder.
3. Double-click index.html, or open the folder in Visual Studio Code.
4. In VS Code, install/use the "Live Server" extension and click "Go Live".

PUBLISH FREE WITH GITHUB PAGES
1. Sign in to GitHub and create a new public repository named: ruchi-2501.github.io
2. Upload index.html, style.css and script.js to the repository root.
3. Open repository Settings → Pages.
4. Under Build and deployment, choose Deploy from a branch, select main and /(root), then Save.
5. Your website will be available at https://ruchi-2501.github.io after GitHub Pages finishes publishing.

You can also use Netlify Drop for a quick deployment by uploading the extracted folder at https://app.netlify.com/drop.
